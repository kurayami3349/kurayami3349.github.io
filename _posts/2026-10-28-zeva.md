We present Zeva, the first framework that enables in-context learning from a robot's own physical interaction experience while keeping the policy model frozen. Zeva employs a Causal Interaction Extractor to encode an executed action and its induced state change into a causal interaction signal, which is stored in a dual-timescale causal memory. ## 1. 问题与背景
{: #problem }

机器人遇到新的物体几何、接触动力学与执行偏差时，相似动作可能产生不同结果。预训练提供通用先验，却未必能预先覆盖部署中的全部物理条件。Zeva 研究的问题是：机器人能否把刚刚执行过的动作及其实际结果保存下来，用这些经验修正后续行为，同时不在部署中更新网络权重？〔§I、§III-A〕

论文将这一过程称为 In-Context Causal Learning（ICCL）。其上下文来自机器人自身交互，也可以由人类遥操作示范初始化；粒度是 action chunk 执行前后的局部 transition。这个设定同时包含单次尝试内部的反馈利用，以及同一任务实例多次重试之间的经验复用。

**阅读提示：episode 与 attempt 不同。** 一个 episode 固定任务实例及其初始配置；一个 attempt 是从初始状态开始的一次连续执行。重试会恢复同一个初始状态。跨尝试记忆仅在这个 episode 内保留，换到下一个 episode 时清空。因此，论文主评测中的 persistent memory 不等于跨任务、跨天持续增长的终身记忆。〔§IV-A.1〕

“Causal”在这里首先指动作与随后观察到的效果被联合编码。论文没有建立结构因果模型，也没有给出在混杂因素下识别物理因果参数的理论保证。阅读时应将“动作—效果表征有用”和“因果关系已被识别”分开。

## 2. 核心贡献
{: #contributions }

1. **将自身交互作为部署期上下文。** 经验单位包含状态、已执行动作和状态变化，而不只是历史图像或任务示范。目标是让策略利用动作造成的效果调整接下来的行为。〔§III-A–C〕
2. **将交互表征与双时间尺度记忆结合。** Causal Transition Encoder（CTE）输出阶段 token 与效果 signal；Brief Interaction Trace（BIT）保留最近的局部交互，Persistent Interaction Memory（PIM）保留同一 episode 中跨重试的经验。〔§III-C–E〕
3. **提供记忆有效性的多种实验。** 除主基准外，作者报告双记忆消融、人类示范 warm-up、跨任务信号替换与表征分析。创新重点是经验表示、记忆组织与策略条件化的组合，并非提出新的力控底层接口。〔§IV〕

摘要中的“first”和对整个领域的概括属于作者主张；这篇阅读笔记没有进行足以确认优先权的完整文献检索。

## 3. 方法
{: #method }

### 整体思路

部署流程可以概括为：**当前观测与任务 → 检索相关历史 → 生成并执行动作 chunk → 观察效果 → 编码并写入记忆 → 下一次决策。** 写入只能在动作执行并观察到结果之后发生。检索和动作生成使用的是已经完成的交互，不使用当前动作尚未发生的结果。〔Algorithm 1〕

输入包括当前观测、语言指令与交互记忆，输出为连续机器人动作。论文基座为 Cosmos3：自回归路径编码多模态上下文，扩散路径生成动作；记忆被映射为 causal prompt，条件化扩散路径的 full-attention blocks。实验分别采用 Nano 与 Edge 版本。论文没有充分交代动作坐标系、控制频率及 chunk 长度，不能仅凭这个结构认定输入输出接口已经可复现。〔Fig. 2、§III-B/E、§IV-A〕

### 关键设计：CTE 编码动作及其效果

以动作块边界为时间索引，论文用视觉 latent 的差分表达观察到的效果。把公式按执行顺序整理，可写为：

$$
d_{t+1}=s_{t+1}-s_t,\qquad
B_{t+1}=\operatorname{GRU}\!\left(B_t,[s_{t+1};u_t;d_{t+1}]\right).
$$

其中，u 是实际执行的控制，B 是循环交互状态。两个投影头再将 B 映射为阶段表示 p 和效果表示 e。阶段用于组织和检索经验，效果用于提供动作响应信息。初始化 B 依赖任务指令与初始视觉状态；初始 token 不算已完成的交互。〔Eq. 1–2、Algorithm 1〕

CTE 的离线训练目标包括三部分：

- **效果预测：** 从动作条件的交互前编码及交互后的 signal 预测固定视觉编码器下的状态变化；辅以动作摘要重建、前后表征对齐和防坍塌正则。
- **任务聚类：** 对轨迹级任务投影做监督对比学习，同任务轨迹作为正样本。该投影与用于保存效果的 signal 有意区分。
- **阶段推进：** 鼓励相邻阶段 token 沿轨迹起终点定义的方向推进。

三者加权形成 CTE 目标。其作用是使记忆单元具备可用的效果与阶段结构；并不是在部署时对每条新 transition 再优化这些损失。〔Eq. 3–6〕

### 关键设计：双记忆与检索

| 组件 | 保存内容 | 更新方式 | 清空时机 |
| :--- | :--- | :--- | :--- |
| BIT | 最近若干已完成交互的效果 signal | 固定窗口，保持时间顺序 | 每次 attempt 开始 |
| PIM | 阶段—效果二元组 | 相似项合并，否则新增 | 新 episode 开始 |

PIM 合并分数为阶段余弦相似度与效果余弦相似度的加权和。超过阈值时，按记录计数求加权均值并归一化。需要注意，加权和过阈值并不在数学上保证两个分量分别超过某个阈值；论文对“同时匹配阶段和动力学”的文字解释比公式本身更强。〔Eq. 8–9〕

推理时，用当前阶段 p 检索 PIM 中阶段最相似的 Top-K 条效果信号。这是学习得到的检索启发式，而不是显式动作阶段标注。BIT 与检索结果经共享投影，与任务及阶段 token 一起进入 Memory Context Encoder，得到策略上下文 M。〔Eq. 10–11〕

### 数据与训练：ICL 能力从哪里获得

**Zeva 需要离线训练策略使用这套上下文。** §III-E.c 明确给出两阶段流程：先训练并冻结 CTE，再联合优化历史投影、记忆编码器、prompt 映射和 policy，以成功或纠正后的动作 chunk 为目标做 conditional action flow matching。部署时才冻结所有神经网络参数，仅更新 BIT/PIM。〔Eq. 12〕

因此，“frozen policy”描述的是部署阶段，不意味着拿一个未接触过这套记忆表示的现成基模，就能直接通过拼接 token 获得 ICCL。结合力反馈研究，更贴切的类比是：先让模型学会解读动作—响应上下文，然后在部署中通过更新上下文适配新条件。

论文说明各基线使用相同任务训练数据、观测与动作接口，但本次阅读的 v2 正文没有充分报告训练轨迹规模、成功与纠正数据的比例、历史上下文采样方式、归一化与数据增强、训练验证划分、训练算力、训练步数及关键超参数。尤其是离线训练时如何构造能对应部署失败历史的上下文，这会直接影响复现与泛化判断，不能自行补成某种训练方案。

## 4. 实验与证据
{: #evidence }

### 实验设置

仿真采用 RoboCasa365-Atomic5 的五个厨房任务：开电水壶、关烤箱门、开微波炉、咖啡杯摆放、打开厨师机机头。每任务 50 个随机 episode，评测两次，Table II 报告两次均值。Zeva 使用 Cosmos3-Nano。〔§IV-A.2〕

真机 ChemLab-Evo 使用 ARX 14-DoF 双臂平台、腕部和第一人称相机，图像分辨率 680×340，工作区 80×60 cm；部署 GPU 为 RTX 4090，基座为 Cosmos3-Edge。七个任务分为原子操作、短序列、复杂长流程三个难度等级。主基准与消融每任务每配置评测 20 个随机 episode。〔§IV-A.3〕

基线包括 LingBot-VA〔原文 [8]〕、Fast-WAM〔[39]〕、Cosmos3〔[18]〕；仿真还包括 Xiaomi-Robotics-1〔[41]〕和 τ0-WM〔[42]〕，真机包括 π0.5〔[14]〕。作者声明使用相同任务训练数据、接口和评测协议，这提供了可比性基础；缺少更完整训练设置和不确定性报告，仍限制了独立核验。

指标包括任务成功率 SR、任务间宏平均成功率，以及长流程的 process score。后者统计按规定顺序完成的最长阶段前缀，占总阶段数的比例；它衡量部分进度，不等于完整任务成功。

### 消融与其他机制证据

双记忆消融覆盖五个真机任务。下表按 §IV-D 的文字描述对应 Table III；各数值为 SR（%）。

| 配置 | 拿试管 | 放烧杯 | 倒水 | 滴定 | 配盐溶液 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| BIT + PIM | 100 | 70 | 80 | 70 | 70 |

### 局限与反例：如何解读“越试越强”

论文的部署期 scaling 使用累计成功率 CSR@K，即前 K 次尝试中至少成功一次的 episode 比例。仿真独立子集从 26% 增至 45%、70%、73%；它与 Table II 的 76.8% 使用不同评测实例，不能串成同一条能力变化曲线。〔§IV-B、§IV-E.1〕

**累计成功率按定义不会随重试下降。** 即使每次尝试都是成功概率固定为 p 的独立试验，累计成功率也会成为 1−(1−p)^K。这只是解释指标的数学例子，不假设实际机器人尝试独立。因而，曲线上升本身不能区分记忆学习收益与增加尝试机会的收益。记忆消融补充了有用证据，但直接确认跨重试学习仍需同预算、同实例的保留记忆与清空记忆比较，以及逐次尝试的成功统计。

v2 还有一处报告口径问题：引言将 26%→73% 写作四次 repeated attempts，§IV-E.1 则明确 Evolve 1–4 是选出的演化里程碑，不是连续尝试编号。这里采用更详细实验节的表述，不把四个点解释为恰好四次尝试。Fig. 1 的 first-attempt 标签与主文通用重试协议的对应关系也需要进一步澄清。

作者明确承认，当前经验来自执行任务时顺带产生的交互，没有主动选择最能减少物理不确定性的动作。其他边界包括：长流程绝对成功率较低；episode 内反复恢复相同初始状态的协议与真实接触条件持续变化有区别；未提供对显式力反馈、力控输出或接触参数辨识的验证。〔§V〕

## 5. 相关工作与我的判断
{: #discussion }

本文相关工作可以沿“部署中什么发生变化”理解。OpenVLA〔原文 [1]〕、π0〔[2]〕提供通用策略先验；RoboTTT〔[10]〕与 WAM-TTT〔[11]〕通过测试时梯度更新实现适配；Zeva 则在离线完成记忆条件化训练，部署时改变外部上下文。这里的比较依据 Zeva 对相关工作的描述，不将其关于其他方法延迟或能力上限的评价视为独立核实的结论。

MemoryVLA〔[33]〕、MEM〔[34]〕以及世界动作模型的历史记忆方法，为策略保存过去发生的事件。Zeva 希望更明确地保存“执行了什么动作，随后发生了什么变化”，并在跨重试时使用。其差异不能简化为“其他方法没有记忆”，而在于记忆单位、训练目标和重试协议。

BehaviorVLA〔[31]〕是循环行为表征与阶段结构的重要前置工作；ALAM〔[29]〕、LAPA〔[30]〕、UniVLA〔[32]〕构成潜动作表示的相关背景。Zeva 在此基础上强调部署经验的持续写入，而非只使用离线学好的静态表示。

**我的判断：** 这篇论文对研究最有价值的部分，是它把“ICL 的内容”具体化为动作—响应 transition，并明确说明策略如何通过离线训练学会使用它。它提供了有实验支持的结构参考；现有结果还不足以将系统视为已解决一般物理条件辨识的通用因果学习器。对是否值得作为复现基座，还需单独核查代码、权重、数据与训练部署一致性，本笔记不代替工程核查。

## 6. Insights · 思考与启示
{: #takeaways }

### ICL 的关键粒度是可归因的交互，而不只是多帧输入

Zeva 将上下文划分为动作块前后的 transition，再组织为 attempt 内与 attempt 间的历史。这说明“支持多组 observation 输入”只是接口条件；是否能利用上下文适配，还取决于模型有没有学习动作与结果的对应关系，以及训练时的上下文是否覆盖部署中的偏差和失败。这里的依据是 CTE 目标与第二阶段策略条件化训练，而非仅由序列长度推断能力。

### 对 force-conditioned policy：实时反馈与历史适配承担不同职责

**以下是基于本文机制的研究推论，不是 Zeva 已有结果。** 对一个已经能接收力反馈的 policy，当前 wrench 可以描述当下受力；此前的动作—力响应历史则可能帮助区分相同瞬时受力背后的不同条件，例如接触位置变化、运动受限或物体顺应性差异。历史的潜在价值是帮助推断隐藏的接触条件，而不是简单增加输入维数。

可借鉴的经验单位是“执行前状态—实际执行动作—执行后的响应”。迁移到力位协同时，视觉、位姿变化和力响应应共同解释交互。不能直接把 Zeva 的视觉 latent 差分替换成单个力差分，就声称完成接触因果建模：动作与力之间的时延、坐标系、控制器行为及外部扰动都会影响可归因性。

### 当前研究设想还多一个训练前提

已获得 force-conditioned policy，意味着它能利用力输入完成任务；这不自动保证它能从历史动作—力响应中辨识新条件。Zeva 的第二阶段训练提示，还需要让策略学会“如何根据这类历史改变决策”。应区分三件事：接受力模态、用瞬时力闭环控制、根据交互历史适配未知条件。前两者成立，并不在逻辑上推出第三者。

### 两个值得继续追问的问题

第一，什么样的交互表示能保留与接触条件有关的信息，同时不被任务身份或视觉外观主导？Zeva 同时展示任务簇分离与跨任务效果近邻，但二者不能单独证明已解耦物理因素。

第二，当接触条件在一次执行中改变时，跨重试积累的旧记忆何时仍然有效？Zeva 的阶段检索和相似度合并没有显式的不确定性或失效机制。对力控 ICL 而言，记忆的适用条件可能与记忆容量同样重要。
