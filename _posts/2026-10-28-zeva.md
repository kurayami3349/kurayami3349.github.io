We argue that robots need to learn from their own physical interactions on the fly during real-world deployment and use this knowledge to inform subsequent actions. We present Zeva, the first framework that enables in-context learning from a robot's own physical interaction experience while keeping the policy model frozen. Zeva employs a Causal Interaction Extractor to encode an executed action and its induced state change into a causal interaction signal, which is stored in a dual-timescale causal memory. For subsequent actions, relevant causal interaction signals are retrieved from memory and injected into the frozen policy model as context. Experiments in simulation and real-world manipulation demonstrate that Zeva achieves the best performance among the compared frontier VLAs and WAMs and, more importantly, enables self-evolution during deployment without gradient updates. ## 1. 问题与背景
{: #problem }

机器人遇到新的物体几何、接触动力学与执行偏差时，相似动作可能产生不同结果。Zeva 研究如何利用部署时的新交互补充预训练先验：把刚刚执行的动作及其实际结果保存下来，作为后续决策的上下文，部署期间保持网络权重冻结。〔§I、§III-A〕

论文将这一过程称为 In-Context Causal Learning（ICCL）。其上下文来自机器人自身交互，也可以由人类遥操作示范初始化；粒度是 action chunk 执行前后的局部 transition。这个设定同时包含单次尝试内部的反馈利用，以及同一任务实例多次重试之间的经验复用。

**评测中的 episode 与 attempt。** 一个 episode 固定任务实例及其初始配置；一个 attempt 是从初始状态开始的一次连续执行。每次重试恢复同一个初始状态，跨尝试记忆在该 episode 内保留，进入下一个 episode 时清空。〔§IV-A.1〕

论文中的“Causal”围绕动作及其引起的状态变化展开。模型联合编码已执行动作和随后观察到的效果，用这种动作—效果表征组织交互经验。

## 2. 核心贡献
{: #contributions }

1. **将自身交互作为部署期上下文。** 经验单位包含状态、已执行动作和状态变化。目标是让策略利用动作造成的效果调整接下来的行为。〔§III-A–C〕
2. **将交互表征与双时间尺度记忆结合。** Causal Transition Encoder（CTE）输出阶段 token 与效果 signal；Brief Interaction Trace（BIT）保留最近的局部交互，Persistent Interaction Memory（PIM）保留同一 episode 中跨重试的经验。〔§III-C–E〕
3. **提供记忆有效性的多种实验。** 除主基准外，作者报告双记忆消融、人类示范 warm-up、跨任务信号替换与表征分析。这些实验分别考察经验表示、记忆组织与策略条件化的作用。〔§IV〕

## 3. 方法
{: #method }

### 整体思路

部署流程可以概括为：**当前观测与任务 → 检索相关历史 → 生成并执行动作 chunk → 观察效果 → 编码并写入记忆 → 下一次决策。** 每次决策检索已经完成的交互；当前动作执行完毕并获得新观测后，再将这次经验写入记忆。〔Algorithm 1〕

输入包括当前观测、语言指令与交互记忆，输出为连续机器人动作。论文基座为 Cosmos3：自回归路径编码多模态上下文，扩散路径生成动作；记忆被映射为 causal prompt，条件化扩散路径的 full-attention blocks。实验分别采用 Nano 与 Edge 版本。〔Fig. 2、§III-B/E、§IV-A〕

### 关键设计：CTE 编码动作及其效果

以动作块边界为时间索引，论文用视觉 latent 的差分表达观察到的效果。把公式按执行顺序整理，可写为：

$$
d_{t+1}=s_{t+1}-s_t,\qquad
B_{t+1}=\operatorname{GRU}\!\left(B_t,[s_{t+1};u_t;d_{t+1}]\right).
$$

其中，u 是实际执行的控制，B 是循环交互状态。两个投影头将 B 映射为阶段表示 p 和效果表示 e：阶段用于组织和检索经验，效果提供动作响应信息。B 由任务指令与初始视觉状态初始化，随后随已完成的交互更新。〔Eq. 1–2、Algorithm 1〕

CTE 的离线训练目标包括三部分：

- **效果预测：** 从动作条件的交互前编码及交互后的 signal 预测固定视觉编码器下的状态变化；辅以动作摘要重建、前后表征对齐和防坍塌正则。
- **任务聚类：** 对轨迹级任务投影做监督对比学习，同任务轨迹作为正样本。该投影与用于保存效果的 signal 有意区分。
- **阶段推进：** 鼓励相邻阶段 token 沿轨迹起终点定义的方向推进。

三者加权形成 CTE 的离线训练目标，使记忆单元获得效果与阶段结构。部署时，训练好的 CTE 负责将新 transition 编码并写入记忆。〔Eq. 3–6〕

### 关键设计：双记忆与检索

| 组件 | 保存内容 | 更新方式 | 清空时机 |
| :--- | :--- | :--- | :--- |
| BIT | 最近若干已完成交互的效果 signal | 固定窗口，保持时间顺序 | 每次 attempt 开始 |
| PIM | 阶段—效果二元组 | 相似项合并，否则新增 | 新 episode 开始 |

PIM 用阶段余弦相似度与效果余弦相似度的加权和计算合并分数。综合分数超过阈值时，按记录计数求加权均值并归一化；否则新增记忆项。〔Eq. 8–9〕

推理时，用当前阶段 p 检索 PIM 中阶段最相似的 Top-K 条效果信号。BIT 与检索结果经共享投影，与任务及阶段 token 一起进入 Memory Context Encoder，得到策略上下文 M。〔Eq. 10–11〕

### 数据与训练：ICL 能力从哪里获得

Zeva 通过两阶段离线训练学习使用交互上下文。先训练并冻结 CTE，再联合优化历史投影、记忆编码器、prompt 映射和 policy，以成功或纠正后的动作 chunk 为目标进行 conditional action flow matching。部署时冻结全部神经网络参数，更新 BIT/PIM 中的交互记忆。〔§III-E.c、Eq. 12〕

离线训练让策略学会解读动作—响应上下文，部署时则通过更新上下文适配新条件。这是论文中“frozen policy”与 ICCL 配合的方式。

## 4. 实验与证据
{: #evidence }

### 实验设置

仿真采用 RoboCasa365-Atomic5 的五个厨房任务：开电水壶、关烤箱门、开微波炉、咖啡杯摆放、打开厨师机机头。每任务 50 个随机 episode，评测两次，Table II 报告两次均值。Zeva 使用 Cosmos3-Nano。〔§IV-A.2〕

真机 ChemLab-Evo 使用 ARX 14-DoF 双臂平台、腕部和第一人称相机，图像分辨率 680×340，工作区 80×60 cm；部署 GPU 为 RTX 4090，基座为 Cosmos3-Edge。七个任务分为原子操作、短序列、复杂长流程三个难度等级。主基准与消融每任务每配置评测 20 个随机 episode。〔§IV-A.3〕

基线包括 LingBot-VA〔原文 [8]〕、Fast-WAM〔[39]〕、Cosmos3〔[18]〕；仿真还包括 Xiaomi-Robotics-1〔[41]〕和 τ0-WM〔[42]〕，真机包括 π0.5〔[14]〕。按论文的实验设置，各方法使用相同任务训练数据、观测与动作接口和评测协议。

指标包括任务成功率 SR、任务间宏平均成功率，以及长流程的 process score。SR 记录完整任务的成功情况；process score 统计按规定顺序完成的最长阶段前缀，占总阶段数的比例，用于记录部分进度。

### 消融与其他机制证据

双记忆消融覆盖五个真机任务。下表按 §IV-D 的文字描述对应 Table III；各数值为 SR（%）。

| 配置 | 拿试管 | 放烧杯 | 倒水 | 滴定 | 配盐溶液 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| BIT + PIM | 100 | 70 | 80 | 70 | 70 |
| 去掉 BIT，仅 PIM | 80 | 50 | 50 | 40 | 55 |
| 去掉 PIM，仅 BIT | 85 | 60 | 70 | 60 | 50 |
| 两者都去掉 | 65 | 40 | 45 | 25 | 35 |

去掉 BIT 后，各任务成功率下降 15–30 个百分点；去掉 PIM 后下降 10–20 个百分点。两种时间尺度的记忆均有贡献，在这组任务中，移除短期记忆带来的降幅通常更大。

**人类示范 warm-up。** 一段任务匹配的遥操作轨迹经 CTE 写入 PIM，随后由冻结策略执行。Fig. 5 展示称重任务的轨迹案例，Fig. 6 给出三项原子任务的曲线。§IV-E.2 报告，示范初始化使放烧杯任务的成功率最高增加 20 个百分点，倒水增加 15 个百分点。〔Fig. 5–6〕

## 5. 相关工作
{: #discussion }

按 Zeva 的相关工作章节，OpenVLA〔原文 [1]〕、π0〔[2]〕提供通用策略先验；RoboTTT〔[10]〕与 WAM-TTT〔[11]〕通过测试时梯度更新实现适配；Zeva 在离线完成记忆条件化训练，部署时更新交互上下文。

MemoryVLA〔[33]〕、MEM〔[34]〕以及世界动作模型的历史记忆方法，为策略保存过去发生的事件。Zeva 以“执行了什么动作、随后发生了什么变化”为记忆单位，结合效果表征训练与跨重试经验复用。

BehaviorVLA〔[31]〕提供循环行为表征与阶段结构的相关思路；ALAM〔[29]〕、LAPA〔[30]〕、UniVLA〔[32]〕构成潜动作表示的相关背景。Zeva 将这类表征用于组织部署时持续产生的交互经验。

## 6. Insights · 思考与启示
{: #takeaways }

### 以动作—响应交互组织 ICL 上下文

Zeva 以动作块执行前后的 transition 为经验单位，并将历史组织为 attempt 内和 attempt 间两个时间尺度。沿着这个设计，可以把 ICL 拆成三个问题：上下文记录什么、如何组织历史、策略如何通过训练学会使用这些信息。

### 对 force-conditioned policy：实时反馈与历史适配承担不同职责

对力反馈 ICL 的一个阅读联想是：当前 wrench 描述当下受力，历史动作—力响应则提供接触条件随动作变化的信息。接触位置、运动约束与物体顺应性，都可以作为组织这类历史时关注的因素。

沿用“执行前状态—实际执行动作—执行后响应”的经验单位，可以把视觉、位姿变化与力响应共同纳入上下文。设计这种表示时，需要考虑动作和力之间的时延、坐标系、控制器行为及外部扰动。

### 训练策略利用历史力反馈

Zeva 的第二阶段训练提供了一个可继续研究的思路：在已有 force-conditioned policy 的基础上，训练策略利用历史动作—力响应调整决策。实时力反馈负责当前闭环，交互历史用于适配接触条件，两者如何共同进入策略值得进一步探索。

### 两个值得继续追问的问题

第一，如何设计交互表示，使其保留接触条件的信息，并能在不同任务和物体外观之间复用？可以结合 Zeva 的任务表征与跨任务效果近邻，继续思考表示学习目标。

第二，当接触条件在一次执行中改变时，如何选择继续保留、更新或淘汰旧记忆？这关系到历史经验的适用时机，也可以作为力控 ICL 的后续研究问题。
