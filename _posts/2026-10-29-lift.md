## 1. 问题与背景
{: #problem }

LIFT 研究如何在 VLA 后训练阶段接入力反馈，使已有策略获得接触响应能力，并加快真机任务学习。视觉语言模型提供任务语义和动作先验，末端六维 wrench 则描述接触过程中力与力矩的变化。两类信息共同帮助机器人判断抓取、插入、碰撞和释放时机。〔§1、§3〕

论文围绕三个目标组织方法：O1 用近期力历史刷新动作；O2 在新增分支初始化时保留预训练策略的输出；O3 联合使用大量纯视觉示范和在线力反馈纠正数据。LIFT 的全称为 Late Reactive Injection of Force for VLA Post-Training。〔§3〕

## 2. 核心贡献
{: #contributions }

1. **反应式力注入。** 在原有 action expert 旁增加 reactive action expert，用 GRU 编码近期 wrench，并通过 cross-attention 注入动作生成过程；视觉语言 KV cache 支持动作块内部重复刷新。
2. **初始化输出等价。** 复制动作专家权重、对齐位置、采用 shifted causal attention，并将力注入残差的输出投影置零，让扩展后的策略从已有动作能力开始训练。
3. **异构数据在线后训练。** 通过 force masking 和 1:1 数据混合，把离线任务示范与当前策略访问状态上的人类纠正统一到 flow-matching 训练中。〔§4〕

## 3. 方法
{: #method }

### 两个训练阶段与数据流

**Stage 1 学任务，Stage 2 学带力反馈的接触执行；Stage 2 持续使用 Stage 1 的数据。** 预训练 π0.5 是整个流程的起点。按照 §4.4，Stage 1 已经构建 LIFT 架构，训练时将力通路 mask 掉。Fig. 4 中的 warmed checkpoint 是完成视觉任务对齐后的模型权重。〔§3、§4.4〕

| 项目 | Stage 1：离线任务对齐 | Stage 2：在线力反馈后训练 |
| :--- | :--- | :--- |
| 数据采集 | 带 iPhone 的手持夹爪 | Flexiv TDK 主从遥操作与机器人在线执行 |
| 数据集 | 固定的视觉示范集 Dv | 持续增长的人类纠正集 Df，加上 Dv |
| 输入 | 语言、图像，力通路 masked | Dv 样本屏蔽力；Df 样本启用实测 wrench |
| 动作监督 | 示范动作 | 离线示范动作与人类在线纠正动作 |
| 训练内容 | 让扩展后的策略对齐目标任务 | 联合训练动作分支、力编码与注入通路 |
| 产物 | warmed checkpoint | 持续更新并回传机器人的 checkpoint |

例如插书任务，Stage 1 的示范让策略学习接近、抓书、移动到书架和插入的大致动作。Stage 2 中，机器人执行当前策略，在侧向碰撞、插入受阻或释放时机需要调整的状态下获得人类纠正；训练同时看到当时的图像、力历史和纠正动作。下一轮策略由这些数据学习接触状态下的动作选择。

### DAgger 如何串起 Stage 2

DAgger 在这里负责**访问状态、获得纠正、聚合数据和再次训练**。策略执行决定它遇到哪些接触状态，人类接管提供这些状态上的动作监督。论文将人类干预帧加入在线数据集 Df，采集的完整 episode 则用于传输和管理。〔§5.1、附录 C、E、J〕

1. 用当前 checkpoint 在机器人上执行任务。
2. 操作者通过 Flexiv TDK 接管并纠正运动。主臂接收从臂的力反馈，操作者可以感受到接触。
3. 将干预期间的图像、同步六维 wrench 和人类控制命令加入 Df。
4. 训练器每个训练步检查新完成的 episode，从 Dv、Df 各采样一半数据。
5. 用 flow-matching 损失更新模型，每 100 个训练步将 checkpoint 同步给推理服务器，继续采集。

这一在线循环采用 DAgger 数据聚合与监督式 flow matching：**专家标签来自人类纠正，base/reactive 两条动作流都拟合数据中的动作目标。** 权重复制负责初始化，DAgger 负责后续的数据闭环。〔§4.2–4.4〕

### 两个 Action Expert 各做什么

视觉语言部分沿用 π0.5 的 PaliGemma 主干，动作侧包含 base action expert 和 reactive action expert。base 分支保留动作块内部的全注意力结构，reactive 分支接收力历史并使用 shifted causal attention。两条分支共享输出投影；推理时两条分支都参与计算，机器人执行 reactive 分支生成的动作。〔§4.1–4.3〕

  <figcaption><strong>原文 Fig. 2 · 双动作专家与力注入架构。</strong> base action expert 提供动作表示，reactive action expert 通过 cross-attention 使用 GRU 编码的六维 wrench 历史。 来源：Wang 等，LIFT，arXiv:2607.14236v3，第 4 页，<a href="https://arxiv.org/pdf/2607.14236v3#page=4">原图</a>。</figcaption>
</figure>

双分支的训练目标为两项 flow-matching 误差之和：

$$
\mathcal L=\left\|v_\theta(x_\tau,\tau,o)-u\right\|_2^2
+\left\|v^r_\theta(x^r_\tau,\tau,o,m)-u^r\right\|_2^2.
$$

两条分支采样独立噪声，使用相同的 flow 时间，分别构造插值与目标速度场；两项损失在一次 forward 中计算并联合回传梯度。这里的 u、uᵣ 是 flow matching 的速度场目标，机器人最终接收的是去噪得到的动作。〔Eq. 1〕

### Shifted Causal Attention 为什么保留初始化输出

用四个动作位置举例，原 base token a₂ 可以访问视觉语言前缀 P 和 a₀、a₁、a₂、a₃。扩展后，reactive token r₂ 可以访问 P、r₀、r₁、r₂，以及后面的 base token a₃。初始化时，权重复制和位置对齐使 r₀:r₂ 对应 a₀:a₂，余下的 a₃ 由 base 分支补齐，于是 r₂ 获得与原 a₂ 等价的上下文。〔§4.2、Fig. 3〕

| 查询位置 | reactive 前缀 | base 分支补齐的后续位置 |
| :--- | :--- | :--- |
| r₀ | r₀ | a₁、a₂、a₃ |
| r₁ | r₀、r₁ | a₂、a₃ |
| r₂ | r₀、r₁、r₂ | a₃ |
| r₃ | r₀、r₁、r₂、r₃ | 空 |

每一行还可以访问共同的视觉语言前缀 P。表中的 a、r 表示动作去噪过程中的 token；base 分支的后续 token 提供当前动作块中的表示。

<figure>
  <img src="/img/arxiv-2607.14236/fig-3-shifted-attention.png" alt="Shifted causal attention" loading="lazy">
  <figcaption><strong>原文 Fig. 3 · Shifted causal attention。</strong> reactive 前缀与 base 分支后续 token 共同构成每个位置的上下文，权重复制与位置对齐建立初始化输出等价性。 来源：Wang 等，LIFT，arXiv:2607.14236v3，第 5 页，<a href="https://arxiv.org/pdf/2607.14236v3#page=5">原图</a>。</figcaption>
</figure>

力 cross-attention 以残差方式加入 reactive 表示。它的输出投影在初始化时为零，因此新增力通路的初始贡献为零；后训练逐步学出有效的力条件更新。两项设计共同建立初始化输出等价性。〔§4.2〕

### 力历史如何与动作时间对齐

力输入为末端六维 wrench：三个力分量和三个力矩分量。单层因果 GRU 将历史编码为隐状态，再投影到动作专家宽度：

$$
m_{t:t+H}=\operatorname{Linear}_{1024}\!\left(\operatorname{GRU}_{512}(F_{t:t+H})\right).
$$

reactive token 通过 cross-attention 查询力记忆。延迟对齐 mask 将第 i 个动作位置可见的力 token 限定为 j≤i−L，论文设置 L=3。按策略的 10 Hz 时间网格，三个位置对应 0.3 秒的对齐偏移；这一偏移将动作位置与推理完成时的执行时间对应起来。〔附录 A、F〕

部署时，先对当前图像和指令计算视觉语言 KV cache，再在动作块内逐步接收新力帧、更新力编码、重新计算动作分支并执行当前动作。每个 chunk 的长度 H=10；切换 chunk 时刷新视觉上下文、噪声与力历史。力记忆在这里覆盖当前 chunk 内的近期接触过程。〔附录 B，Algorithm 1〕

### 混合数据怎样训练同一个模型

Dv 样本用零值占位以保持张量形状，并在 cross-attention 之前屏蔽编码后的力记忆，同时屏蔽力通路梯度。Df 样本使用真实 wrench，更新力编码器、注入模块和动作策略。1:1 指的是每次更新中两类样本的采样比例；在线数据缓冲区会随采集持续增长。〔§4.3、附录 C〕

## 4. 实验与证据
{: #evidence }

### 任务评分与评测协议

**任务评分 stage 表示完成进度，训练 Stage 表示模型学习流程。** 每个 checkpoint 做三组、每组十次自主 rollout，并计算 95% 置信区间。毛巾和插书报告阶段分数，Hanoi 报告二元成功率。Collected samples 统计在线采集的人类干预帧。〔§5.1、附录 I〕

| 任务 | 完成进度与评分 |
| :--- | :--- |
| 毛巾折叠 | 抓住第一角：0.25；完成第一次折叠：0.5；抓住第二角：0.75；完成第二次折叠：1.0 |
| 插书 | 抓起书并完成无碰撞插入：0.5；继续完成闭合夹爪、推书脊至完全入位并脱离接触：1.0 |
| Hanoi 套环 | 环完全落到柱底：1；其余执行结果：0 |

毛巾分数取最高完成阶段。例如十次执行中五次得 1.0、五次得 0.5，平均分就是 0.75。这个示例用于说明评分含义。插书的 0.5 与 1.0 则区分初步插入和完整的入位、脱离流程。

论文以相同在线 DAgger 流程的视觉策略为主要比较对象，并加入单帧力、固定纠正数据、离线手持示范和轻量 residual policy 等配置。〔§5.1〕

### 消融与分析

- **近期力记忆与反应式更新：** 插书和 Hanoi 中，完整 LIFT 在峰值与后续表现上优于单帧力配置；毛巾的较简单接触过程也能有效利用单帧力。〔§5.3〕
- **在线纠正数据：** 使用固定纠正缓冲区的 Offline DAgger 配置在三项任务中分数较低，插书得分为零；持续采集使训练数据包含当前策略产生的接触偏差。〔§5.5〕
- **离线、在线混合比例：** 毛巾任务比较 0:1、1:1、1:2，两个混合配置优于纯在线数据，1:1 提升更快；主实验采用 1:1。〔附录 K.1、Fig. 10〕
- **轻量残差策略：** 对照系统冻结视觉基座，训练约 28M 参数的因果 Transformer 与力 GRU，输出加性位置修正。论文报告完整 LIFT 得分更高，并将差异与较大修正需求、稀疏干预目标联系起来。〔§5.6、附录 H〕

### 物体与视觉条件变化

论文对最终 checkpoint 评测了替换毛巾或书、替换桌布、添加紫色侧光等条件。每次变化保留机器人初始位姿和目标物体位置，改变指定因素。Fig. 6 展示各条件下的任务分数，作者报告多数测试条件保持了原有表现。〔§5.4、附录 L〕

## 5. 相关工作
{: #related-work }

LIFT 将反应式动作生成接入通用 VLA 后训练。π0/π0.5〔原文 [4,5]〕提供视觉语言条件动作先验；RDP〔[10]〕与 ImplicitRDP〔[11]〕提供慢视觉、快接触反馈以及 GRU 力历史的相关设计。LIFT 进一步通过权重复制、shifted causal attention 和零初始化，组织预训练动作专家与新增力通路的衔接。

ForceVLA〔[19]〕、TA-VLA〔[20]〕、ForceVLA2〔[21]〕和 FAVLA〔[22]〕围绕力信息融合、力矩历史及动作更新开展研究。LIFT 的主线是使力模态同时参与反应式执行和在线纠正训练。

DAgger〔[23]〕及人类交互扩展 HG-DAgger〔[24]〕为 learner-visited states 上的纠正提供方法基础。LIFT 使用固定视觉数据与持续增长的力纠正数据，并借鉴 RLPD〔[31]〕的对称采样策略，将两类数据按 1:1 混合。〔§2、§4.3〕

## 6. Insights · 思考与启示
{: #takeaways }

### Force-conditioned policy 的能力可以分层建立

阅读联想：围绕力控 VLA 与 ICL，LIFT 提供了一个分阶段建立策略能力的思路：先通过视觉示范获得任务行为，再通过真实接触中的力反馈和纠正动作学习反应式执行。由此形成的 force-conditioned policy 已具备力模态接口、时序编码和动作生成之间的训练联系。

### 接触历史可以解释当前力的含义

插书例子突出体现了历史信息的作用：当前负载需要结合此前的力变化，才能对应到正在插入、已经入位或需要脱离等阶段。这启发后续研究把动作、位姿变化与力响应共同作为 context，进一步研究模型如何依据交互过程推断当前接触条件。

### 从 LIFT 的短期反应走向 ICL 适配

LIFT 的 GRU 历史在当前 chunk 内编码接触过程，DAgger 则通过更新权重吸收在线纠正经验。围绕 ICL，可以继续研究跨 chunk 或跨尝试的动作—力响应上下文，以及这种上下文如何帮助策略在新的接触条件下调整行为。这一方向把关注点放在“历史中哪些交互信息值得保留，以及策略如何学会使用这些信息”。
