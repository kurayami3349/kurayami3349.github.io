However, existing Vision-Language-Action (VLA) models struggle to exploit tactile feedback for gentle manipulation due to scarce aligned vision-tactile-language data and the lack of effective closed-loop force feedback mechanisms. To address these challenges, we introduce Tabero, a benchmark and model suite for gentle, language-conditioned robotic manipulation that demands fine-grained contact force perception. First, the Tabero benchmark addresses the scarcity of tactile data by presenting a data-efficient pipeline that repurposes open-source robot manipulation trajectories to generate diverse vision-tactile-language tasks, and establishes a multidimensional evaluation protocol that measures task success alongside physical interaction quality. Second, we propose Tabero-VTLA, an architecture with a decoupled force-position command interface; the resulting force-position commands are executed by a fixed hybrid controller to enable real-time, force-aware manipulation. Evaluated on Tabero, our model maintains high task success while reducing average grip force by over 70% under gentle instructions, demonstrating its ability to modulate interaction forces based on multimodal experience. Our code is publicly available at https://github.com/NathanWu7/Tabero."

## 1. 问题与背景
{: #problem }

Tabero 研究语言如何调节机器人的接触力度：同样是“把物体放进篮子”，加入 gently、softly、firmly 等词后，机器人需要改变夹持力，同时完成搬运。作者把这个问题拆成数据、策略和控制三个部分：在仿真中重新执行已有轨迹，生成同步触觉与力数据；训练策略预测位置和目标力；用实时反馈控制器跟踪这些命令。

这使“温柔操作”成为可以度量的过程。任务成功率回答物体是否到达目标，接触期间的平均力与高峰力回答机器人怎样完成任务。全文的算法实验在 Tabero 仿真平台上展开，主要训练评测使用 LIBERO Object 中的九个搬运任务。（§1、§3.6、§4.2；附录 C）

## 2. 核心贡献
{: #contributions }

1. **可复用的触觉数据生成管线。** 在 Isaac Lab 中重建开源任务，重放轨迹并记录视觉、触觉图像、marker 位移场、指尖力及本体状态；通过控制参数变化生成不同力度。
2. **语言条件下的力—位置命令接口。** 基于 π₀ 的 Tabero-VTLA 同时预测动作与目标指尖力，夹爪和机械臂分别使用导纳反馈调节位置。
3. **覆盖交互过程的评测。** 在成功率之外记录抓握力和施加力，比较触觉输入形式、力监督和控制器组成。25% gentle 数据设置下，平均抓握力从 firm 指令的 31.3 N 降为 8.5 N，成功率分别为 87% 和 79%。（Table 2）

## 3. 方法
{: #method }

### 先生成语言、动作与力对应的数据

数据迁移从任务环境开始：作者重建物体、机器人初始位姿和成功判据，针对触觉夹爪的几何变化对齐 TCP，并用高增益关节 PD 控制器重放轨迹。相机包含腕部与第三视角 RGB-D；模拟 GelSight 提供 320×240 触觉图像和 11×9 marker 网格。各模态以 **20 Hz 同步采样**。（§3.1–3.2）

力度变化由夹爪阻抗参数生成。接触稳定后，抓握力近似随位置刚度与压入量的乘积变化；接触瞬间的冲击还受阻尼影响。作者采用三组刚度／阻尼：`(2000,100)`、`(500,25)`、`(200,10)`，对应 100%、25%、10% 设置。单位分别为 N/m 和 N·s/m。高力度轨迹配 firmly/tightly，低力度轨迹配 gently/softly，副词随机放在句首或句尾；动作保存连续夹爪开度。（§3.3、§4.2；Table 10）

| 数据集 | 力度设置 | 夹爪表示及训练配置 |
| :--- | :--- | :--- |
| A | 100% 与 25% | 连续开度；触觉 marker 场；用于常规 gentle 操作与控制器分析 |
| B | 100% 与 10% | 连续开度；用于极低力操作、模态消融与语言泛化 |
| C | 100% 与 10% | 二值开／关；视觉语言变体；用于动作表示对照 |

### 高层策略读入什么、输出什么

Tabero-VTLA 基于 π₀（JAX）和 flow matching。视觉、语言与触觉形成条件信息，action expert 预测后续的力—位置序列。附录列出 **13 个有效动作维度，padding 至 32 维，力槽占 6 维**。输入中的 6D force 由左右指尖各一个三维力向量拼接而成，其物理含义是双指接触力。（§3.4；Tables 5–7）

作者比较三类触觉编码方式：

- **Marker 场：** 每指使用静止参考帧与 8 帧历史 marker 坐标；两层因果 TCN（kernel=3）编码时间变化，作为 prefix token 输入骨干。
- **触觉图像：** 左右指的历史触觉图拼成一张图，经视觉编码器后参与多模态推理。
- **指尖力：** 8 帧、每帧 6 维的序列进入两层 MLP；分别比较 encoder prefix 注入（Force E）和 action expert suffix 注入（Force D）。

三种表示提供不同层面的接触信息：图像描述局部接触几何，marker 随时间的运动记录表面形变，指尖力直接给出各方向的作用强度。参考帧为 marker 运动提供静止基准，历史序列保留接触建立和变化的过程。实验通过统一骨干与训练超参数，比较这些信息经不同入口进入模型后对目标力预测的作用。（§3.2、§3.4、§4.4）

训练将位置、夹爪开度与目标力共同放入连续动作向量。对噪声与目标动作插值后预测速度场，损失按维度加权：

$$
\mathcal L=\frac{1}{D}\sum_{d=1}^{D}w_d\left(v_{t,d}-(a_d-\epsilon_d)\right)^2.
$$

位置等维度权重为 1，力维度使用独立权重。附录配置的力监督权重为 **0.1**，去掉力监督的消融为 0。训练采用 LoRA，50,000 steps、batch size 32，cosine 学习率从峰值 2.5×10⁻⁵ 衰减到 2.5×10⁻⁶。（Eq. 2；Tables 5–8）

### 实时闭环怎样接上策略输出

<p class="paper-sidenote"><a href="https://arxiv.org/pdf/2605.27886v1#page=5">查看原图</a> · <strong>原文 Fig. 3 · 感知、命令与执行的接口。</strong> 上半图展示触觉图、marker 场与指尖力的注入位置，下半图将抓握与物体平移的力反馈分开处理。来源：Tabero，arXiv:2605.27886v1，第 5 页。</p>

高层负责选择动作和目标力，固定低层控制器提供顺应性。设左右指尖的局部接触力为 $$F_L,F_R$$，局部 z 轴为抓握法向。论文定义：

$$
F_{\mathrm{grip}}=2\min\left(\lvert F_{L,z}\rvert,\lvert F_{R,z}\rvert\right),\qquad
F_{\mathrm{applied}}=-(F_L+F_R).
$$

这两个量对应“把物体夹多紧”和“通过接触向物体施加多大合力”。机械臂回路先把目标施加力从接触坐标系旋转到基座坐标系，再用目标力与实测力之差修正预测位置，随后通过微分逆运动学执行。夹爪回路对预测抓握力加前馈系数，对实测力做指数平滑，再把力误差转成开度修正；死区过滤小修正，最终命令限制在夹爪开度范围内。（§3.5，Eqs. 3–8）

部署时仍使用 100% 的底层阻抗设置，语言所要求的力度由策略目标与反馈回路共同实现。模型可以在较慢的动作序列预测过程中提供目标，控制器持续使用实测力跟踪目标。论文的控制器消融重点考察抓握力闭环。（§4.2–4.3）

## 4. 实验与证据
{: #evidence }

### 数据迁移、指标与比较设置

跨平台验证覆盖 LIBERO Spatial、Object、Goal、10 四个任务组：原始 MuJoCo 数据平均成功率为 85%，相同机器人配置迁移到 Isaac Lab 后为 76%；触觉夹爪在 100%、25%、10% 设置下分别为 60%、50%、36%。这些数值描述**轨迹重放及数据保留率**。后续策略训练使用九个 Object 搬运任务，分别把汤罐、奶酪、沙拉酱、牛奶等物体放进篮子。（Table 1、Table 11）

模型评测同时报告成功率 SR，以及单位为 N 的四个力指标：AG、AA 是接触期间抓握力、施加力的均值；MG、MA 是每个 episode 中对应力值最高 5% 样本的均值，用于刻画瞬态高峰。（§3.6）

### 力度与成功率

| 设置／问题 | Firm 指令 | Gentle 指令 | 原文位置 |
| :--- | :--- | :--- | :--- |
| A：25% gentle | SR 87%；AG 31.3 N；MG 61.3 N | SR 79%；AG 8.5 N；MG 19.9 N | Table 2 |
| B：10% gentle | SR 86%；AG 32.4 N；MG 62.7 N | SR 52%；AG 3.7 N；MG 11.4 N | Table 2 |
| C：二值夹爪对照 | SR 86%；AG 35.8 N | SR 87%；AG 34.6 N | Table 2 |

由表中均值计算，A 的 gentle 指令使 AG 降低约 **72.8%**；B 降低约 **88.6%**，同时呈现更低的任务成功率。C 的两类指令对应相近抓握力。数据表示、力监督和反馈执行因此共同构成了论文的力度调节链路。

### 模态与控制器消融

Table 3 在 B 上比较统一训练设置的结构变体。加入力监督 FS 后，Force E+FS 的 gentle SR 为 49%，Img+FS 为 48%，Field+FS 为 52%；Force D+FS 为 31%。单独使用 FS 的配置达到 45%。带有 marker 历史与力监督的 Field+FS，在 firm/gentle 下分别达到 86%/52%，AG 为 32.4/3.7 N。作为对照，Field、Img 和 Force E 的 gentle SR 均为 1%。这组实验把“提供接触感知”和“学习目标力输出”分别落到了可检查的配置上。（Table 3）

<p class="paper-sidenote"><a href="https://arxiv.org/pdf/2605.27886v1#page=8">查看原图</a> · <strong>原文 Fig. 7 · 预测力如何落实到实际接触。</strong> 蓝线为预测力，红线为实测力；(a)(b) 为完整控制器，(c) 移除前馈后实测力低于目标，(d) 移除导纳后出现滑落。来源：Tabero，arXiv:2605.27886v1，第 8 页。</p>

控制器分析在 A 的 Object task 1 进行。完整反馈与前馈帮助实测抓握力跟随预测值；去掉前馈后出现稳态偏差，去掉导纳后出现滑落。（Fig. 7）

语言泛化在 B 上使用训练中未出现的 lightly 和 forcefully。Field+FS 对它们分别给出 AG 14.5 N、18.1 N，SR 为 61%、64%；训练内 gently/softly 为 3.7 N，firmly/tightly 为 32.4 N。这些结果呈现了语言语义与接触力度之间的插值式响应。（Table 4）

## 5. 相关工作
{: #related-work }

Tabero 继承 LIBERO（Liu et al., 2023）的任务与轨迹，结合 TacEx（Nguyen et al., 2024）、Taxim（Si & Yuan, 2022）和 FOTS（Zhao et al., 2024）生成触觉模态。π₀（Black et al., 2025b）提供连续动作 flow-matching 基础，Tabero 将目标接触力加入预测空间。

触觉注入对照分别借鉴 Tactile-VLA（Huang et al., 2025）、VTLA（Zhang et al., 2025a）与 TA-VLA（Zhang et al., 2025b）。Tabero 进一步把双指夹持力和对物体的施加力分为两条控制回路，并用语言副词组织力度数据。以上引用沿用原文的作者—年份格式，对应 §2 与 References。

## 6. Insights · 思考与启示
{: #takeaways }

### 批判性阅读：柔和指令的效果，会不会混入示范筛选偏差？

数据采集保留成功轨迹，而不同刚度设置的采集成功率不同。低刚度留下的样本可能更偏向容易接触的状态，策略观察到的“柔和”因而同时关联力水平和场景选择。

**区分实验。** 可在相同物体、初始状态和轨迹条件下随机改变指令，并保留采集失败，比较实际力分布与成功率。再改变接触面积和摩擦，测量滑移与损伤：相同平均握持力是否安全，取决于这些物理条件，离散语言档位的标定应单独检验。

### 进一步的阅读联系

**阅读联想：把 force-conditioned policy 看成两层接口。** Tabero 清楚展示了策略目标与实时反馈的分工：模型从历史触觉和任务语义选择目标力，控制器把目标变成物理响应。沿这个分工思考 ICL，历史 context 可以承担“从此前动作及其力响应中辨认接触条件”的角色，低层继续负责跟踪当前目标。

**阅读联想：动作—响应对能为触觉历史赋予因果语境。** 论文使用八帧触觉历史来编码当前接触状态。面向接触适配，一个自然问题是：将这段历史与执行过的开度、位移和目标力对齐后，模型能否进一步辨认物体刚度、摩擦与滑移趋势，并据此改变下一段目标力？这把 context 的粒度具体化为一个短时交互片段。

**阅读联想：目标力也是可检查的中间决策。** Tabero 同时暴露预测力、实测力和任务结果。对于后续力位协同 ICL，三者形成一条可追踪链路：context 改变了怎样的力目标，控制器实现了怎样的接触，最终带来了怎样的任务表现。
