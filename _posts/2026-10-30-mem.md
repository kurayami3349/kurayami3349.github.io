However, in complex multi-stage real-world tasks, the robot's memory must represent past events at multiple levels of granularity: from long-term memory that captures abstracted semantic concepts (e.g., a robot cooking dinner should remember which stages of the recipe are already done) to short-term memory that captures recent events and compensates for occlusions (e.g., a robot remembering the object it wants to pick up once its arm occludes it). We introduce Multi-Scale Embodied Memory (MEM), an approach for mixed-modal long-horizon memory in robot policies. MEM combines video-based short-horizon memory, compressed via a video encoder, with text-based long-horizon memory. Together, they enable robot policies to perform tasks that span up to fifteen minutes, like cleaning up a kitchen, or preparing a grilled cheese sandwich. Additionally, we find that memory enables MEM policies to intelligently adapt manipulation strategies in-context."

## 1. 问题与背景
{: #problem }

MEM（Multi-Scale Embodied Memory）把机器人记忆分成两个时间尺度：短期视觉记忆保存遮挡前的物体、抓取姿态和最近失败；长期语言记忆保存已完成步骤、物品去向与待办事项。论文用这种多模态分工，将 π0.6 扩展到最长约 15 分钟的任务，并学习根据近期尝试调整操作策略。

厨房准备材料需要记住已经取出的食材，纠正一次抓空则需要保留刚才的视觉与状态细节。两类信息的分辨率需求不同，MEM 因而将语言摘要和紧凑视频表征结合到高低层策略中。

## 2. 核心贡献
{: #contributions }

1. 高层策略同时预测下一子任务和更新后的语言记忆，低层策略以子任务及短期观测历史生成连续动作。
2. 在已有 ViT 中引入时空分离注意力，将视频历史压缩到当前帧的输出 token，控制传给 VLA 主干的序列长度。
3. 通过多源预训练与保留失败上下文的纠正数据，获得部分可观测任务处理、长任务记忆和上下文内策略调整能力。

## 3. 方法
{: #method }

### 高低层策略与两种记忆

高层输入总体目标、当前观测和已有语言记忆，输出下一子任务以及更新后的记忆摘要；低层输入目标、子任务与近期图像／本体状态序列，输出动作块。高层通过子任务选择，将长期任务信息传递给低层执行。

<p class="paper-sidenote"><a href="https://arxiv.org/pdf/2603.03596v2#page=4">查看原图</a> · <strong>原文 Fig. 2 · 两种记忆连接高低层策略。</strong> 语言摘要承担长期语义记录，视频编码承担近期空间与交互细节。 来源：MEM，arXiv v2，PDF 第 4 页。</p>

语言记忆的训练标签由离线标注管线产生：将示范中的子任务描述及成功／失败标志交给预训练 LLM，要求总结仍与后续执行相关的信息。标签会压缩重复和过时内容，例如把多个具体碗的描述汇成“已把三个碗放进右上橱柜”。训练后的高层策略自行预测记忆更新。

这种摘要还处理重复尝试。机器人多次执行“拿起碗”后才成功时，语义记忆可以在成功后记录结果；训练与部署中的语言历史因而保持相近的事件粒度。

### 短期视频编码

视频编码器继承单图 ViT 权重，每四层加入时间注意力：同一帧内进行空间注意力，同一 patch 位置沿时间进行因果注意力。若每帧有 $$n$$ 个 patch、历史长度为 $$K$$，时空分离将注意力复杂度由 $$O(n^2K^2)$$ 改为 $$O(Kn^2+nK^2)$$。

上层保留当前帧输出，将历史信息压入当前表征。传入 VLA 主干的视觉 token 数因此与单帧配置相当。结构复用已有投影权重，加入固定正弦时间编码，并令当前时刻编码为零，使单帧初始化与原视觉编码器对齐。每个历史本体状态通过线性层编码成一个 token。

### 基座与学习阶段

MEM 集成到 π0.6：Gemma3-4B VLM、SigLIP 视觉编码器与 860M 流匹配动作专家。训练同时使用离散 FAST 动作 token 预测和连续动作专家目标；动作专家梯度在 VLM 处停止。图像分辨率为每路 448×448，最多四路相机。

| 阶段 | 数据与上下文 | 学习内容 |
| :--- | :--- | :--- |
| 多源预训练 | 遥操作、策略 rollout、人工纠正、视觉语言和视频语言数据；6 帧、间隔 1 秒 | 使用短期历史的通用表征与动作能力 |
| 长任务训练 | 带子任务及结果标注的示范，离线生成的记忆摘要 | 下一子任务和语义记忆更新 |
| 目标任务 post-training | 任务示范或纠正数据；视频历史可扩大到 18 帧、约 54 秒 | 任务技能和更长观测记忆 |
| 在线执行 | 更新中的视频／状态历史与语言摘要 | 固定参数下依据当前 context 调整行为 |

真机执行采用推理时或训练时 Real-Time Chunking，实现异步动作块推理。Fig. 3 在单张 H100、四路相机上显示，16 帧直接输入约需 3.5 秒；视频编码器配置保持在图示 300 ms 阈值以内。

### ICL 能力如何获取

筷子任务中，机器人在变化桌高下尝试抓取，人类在抓空后接管并展示修正动作；训练时，将失败尝试保留在修正动作之前的短期记忆中。开冰箱数据也包含错误开门方向及随后的纠正，部分示范通过操作者探索开门机制采集。

随后直接以这些数据微调带记忆策略。监督目标是后续动作，context 中包含导致策略改变的前序尝试。在线时，模型通过历史识别已尝试的策略，并调整抓取高度或开门方向。对照组使用同一批介入数据微调无记忆 π0.6。

### 记忆形式与预训练

对照均建立在 π0.6 上，包括逐帧编码再平均池化的 Pool Memory、仅历史本体状态的 Proprio Memory，以及 MEM 视频编码。该组比较使用短期记忆配置。

<p class="paper-sidenote"><a href="https://arxiv.org/pdf/2603.03596v2#page=8">查看原图</a> · <strong>原文 Fig. 8 · 六类记忆任务的对比。</strong> 纵轴为按各任务评分规则得到的 task progress，展示视觉、本体与联合时间表征的差别。 来源：MEM，arXiv v2，PDF 第 8 页。</p>

Fig. 8 中 MEM 在六种记忆任务上均取得更高进度分数，平均约 74%，对应无记忆约 30%、池化约 35%、本体历史约 40%（图中读数）。Fig. 9 进一步比较记忆参与预训练与只在目标任务 post-training 引入记忆：平均进度约为 74% 对 50%。两者都从已有机器人学习基础出发，差别在于记忆机制是否参与了广泛预训练。

Fig. 6 分别去掉视频和语言记忆，显示两种尺度对长任务都有作用；直接累计子任务指令的语言历史版本成绩也低于预测压缩摘要的版本。Fig. 10 展示了模型在折叠衣物、整理桌面、搭纸盒等灵巧任务上的表现。

## 5. 相关工作
{: #related-work }

MEM 使用 π0.6 [35,36] 的通用操作基础，结合时空分离视频注意力 [1,3] 与机器人记忆建模。Pool Memory [20] 压缩逐帧视觉编码，Proprio Memory [53] 保存本体历史；MEM 在视觉编码器内部处理时间关系，并用语言摘要承担较长尺度的语义记忆。RTC [6,7] 连接动作块生成与实时执行。

## 6. Insights · 思考与启示
{: #takeaways }

### 批判性阅读：压缩后的“已完成”记录，怎样被后续证据纠正？

语言摘要保留事件结果，近期视频保留细节。如果高层误把一次失败写成“已完成”，原事件移出视频窗口后，后续决策可能持续读取这一错误状态。记忆长度与结果可靠性因此是两个不同问题。

**区分实验。** 构造当前画面相同、此前子任务实际结果不同的轨迹，分别提供正确、缺失和错误的摘要，并让后续观测显露矛盾。比较任务选择、纠错时延和重复操作次数，能检验模型是否更新事件判断，还是主要沿用摘要中的阶段标签。

### 进一步的阅读联系

**上下文内适配有具体的监督结构。** MEM 把“失败尝试—修正动作”作为连续训练材料，保留失败信息作为后续动作的条件。这里能够直接看到：推理时的适配能力，与训练时如何组织历史和监督目标紧密相连。

**基础能力与目标任务纠正分工明确。** 视频记忆参与多源预训练，建立读取历史的基础；纠正数据再教会策略如何利用特定失败信息改变行为。这个分工回应了新增物理 context 时对基模准备程度的关注。

**对动作—力 context 的联想。** 抓取和开门的前序尝试提供了关于环境约束的证据。若把交互响应表示为动作和力序列，类似的时间结构有助于思考“哪次动作揭示了什么接触条件”。短期响应细节和长期成功／失败摘要也可能需要不同表达粒度。
