We present WAM-TTT, a test-time training framework for steering world action models from raw human videos. Rather than treating human videos as trajectories to imitate, WAM-TTT absorbs them into a lightweight adaptive memory inside a frozen WAM through self-supervised video prediction. To make this memory useful for control, we introduce a meta-training stage that aligns human demonstrations with robot behaviors using paired human-robot data and a key--value memory reconstruction objective. ## 1. 问题与背景
{: #problem }

WAM-TTT 研究如何用一段人类操作视频，为已经训练好的机器人模型指定新的任务变体和操作方式。用户可以演示“怎样递饮料”“怎样把物品换位”，机器人随后在自己的身体和场景中执行相应行为。论文把这个接口建立在 World-Action Model（WAM）上：世界模型负责预测视觉变化，动作模型负责生成机器人动作，两者共享信息，因此人类视频中的任务过程可以通过视觉动力学影响动作生成。（§1）

核心设计是把视频写入一组 **fast weights（快速权重）**。这组权重承担可更新的记忆，训练好的 WAM 承担视觉理解与机器人控制知识。作者先用配对的人类—机器人数据教会记忆如何服务于动作预测，再在部署时用用户视频更新记忆。这形成了“先学会适配，再通过新视频适配”的两阶段流程。（§3、Fig. 2）

## 2. 核心贡献
{: #contributions }

1. **为 WAM 的视频分支加入可适配记忆。** 人类视频通过自监督预测与键值重建写入快速权重，机器人视频特征查询这份记忆，再通过原有视频—动作交互影响控制。
2. **用元训练建立人类信息与机器人行为的联系。** 内层根据人类视频更新快速权重，外层用配对机器人轨迹的视觉和动作目标评价适配结果，并学习记忆的投影、初始化和 WAM 参数。
3. **在三个真机平台上评估视频引导能力。** 九项任务的家庭环境平均任务进度为 46.2%，LDA 基座为 32.5%，直接视频上下文基线 WAM-ICL 为 7.1%。（§3–4、Table 1）

## 3. 方法
{: #method }

### 整体思路：视频写入记忆，机器人读取记忆

基座是 LDA [23]。其 diffusion transformer 同时包含处理视觉 latent tokens 的 **video expert** 和处理机器人动作 tokens 的 **action expert**，两个 expert 通过 joint attention 交换信息。WAM-TTT 在视频 expert 的每层输出上增加一个 TTT 残差分支。部署时，当前观测和任务条件经过 WAM，最终输出一段机器人动作。（§3.1、式 1–2、9）

<p class="paper-sidenote"><a href="https://arxiv.org/pdf/2607.06988v2#page=3">查看原图</a> · <strong>原文 Fig. 2 · 三个环节连接起来的适配流程。</strong> 左侧是共享信息的视频与动作 expert；中间学习人类视频记忆与机器人查询之间的联系；右侧用用户视频更新快速权重，再执行机器人任务。来源：WAM-TTT，arXiv v2，PDF 第 3 页。</p>

每个 TTT 分支包含慢投影 $$\theta_K,\theta_V,\theta_Q,\theta_O$$ 和一个小型 MLP $$f_W$$。人类视频特征生成键 $$K_h$$ 和值 $$V_h$$，机器人视频特征生成查询 $$Q_r$$。快速权重 $$W$$ 通过学习键到值的映射储存人类视频，机器人查询再读取与当前视觉状态相关的信息：

$$
\Delta z_{\mathrm{TTT}}=\theta_O f_W(Q_r),
\qquad z^{(\ell+1)}=\hat z^{(\ell+1)}+\Delta z_{\mathrm{TTT}}.
$$

例如，人类演示中包含“拿起物品—转移—释放”的过程。训练将相近任务阶段的人类视觉信息和机器人行为联系起来；执行时，机器人当前特征查询已写入的记忆，获得能够影响下一步动作的视觉残差。附录 A 把这一机制解释为参数化的 cross-attention：显式键值序列的信息由 MLP 权重承载。（§3.1–3.2、附录 A）

### 两层目标分别教会什么

元训练样本是一对完成人类操作和机器人操作的轨迹。作者按归一化阶段对齐：机器人时刻 $$t$$ 在长度为 $$T_r$$ 的轨迹中对应 $$\phi=t/T_r$$，再选人类视频中阶段最接近的帧。该配对让两种身体的相近任务阶段形成训练联系。（§3.2）

**内层负责写入人类视频。** 从可学习初始化 $$W_{\mathrm{init}}$$ 出发，快速权重优化两个目标：视频预测损失 $$\mathcal L_{\mathrm{vg}}^{\mathrm{human}}$$，以及让 MLP 从人类键恢复人类值的记忆重建损失 $$\mathcal L_{\mathrm{KVM}}$$：

$$
\begin{aligned}
\mathcal L_{\mathrm{adapt}}
&=\mathcal L_{\mathrm{vg}}^{\mathrm{human}}
+\lambda\sum_\ell\mathcal L_{\mathrm{KVM}}^{(\ell)},\\
\mathcal L_{\mathrm{KVM}}
&=\frac{1}{BL_hd}\left\|f_W(K_h)-V_h\right\|_2^2,\\
W_{i+1}&=W_i-\eta\nabla_{W_i}\mathcal L_{\mathrm{adapt}}.
\end{aligned}
$$

视频损失通过完整的 WAM 视频前向计算，梯度进入各层 TTT 残差；键值重建则在每层约束记忆的写入。两项监督都由人类视频自身提供。（§3.2，式 3–5；Algorithm A.1）

**外层负责让这份记忆改善机器人预测。** 更新后的 $$W_N$$ 被机器人特征查询，外层计算配对机器人数据上的视频扩散和动作扩散损失。梯度穿过内层更新，联合优化 WAM、慢投影与 $$W_{\mathrm{init}}$$。每个训练样本结束后，快速权重重新从初始化开始。外层因此学习的是“怎样经过一次人类视频更新，得到对机器人动作有用的记忆”。（§3.2，式 6；附录 A）

### 从训练到执行，哪些参数在变

| 阶段 | 输入与监督 | 更新内容 | 产物 |
| :--- | :--- | :--- | :--- |
| 基座 | 预训练 LDA | 已获得视觉—动作联合模型 | WAM 初始化 |
| 人类—机器人元训练 | 配对视频与机器人动作；内层人类自监督，外层机器人预测 | WAM、慢投影、快速权重初始化；内层临时快速权重 | 学会吸收人类视频的模型 |
| 测试时适配 | 部署场景中的一小批人类 RGB 视频 | 视频分支快速权重 $$W$$ | 当前任务记忆 $$W_N$$ |
| 机器人 rollout | 当前机器人观测、任务条件、已适配记忆 | 所有参数与 $$W_N$$ 固定 | 连续动作块 |

测试时仍采用视频预测和键值重建的联合目标。人类演示提供的是像素序列，更新对象集中在视频分支的快速权重。完成适配后，机器人在整个 rollout 中复用这份固定记忆。（§3.3，式 7–9）

### 数据与实现设置

数据集包含 **2,286 对人类—机器人轨迹、9 项任务**，其中 Unitree G1 为 600 对、Galbot 双指夹爪为 544 对、Galbot Sharpa 为 1,142 对。机器人示范在标准操作间通过遥操作采集，人类视频由 GoPro 第一视角录制。附录 B 说明人类配对视频在实际家庭环境录制，测试适配时再录制部署场景视频。（§4.1、附录 B）

LDA 配置使用 Qwen3-VL-4B-Instruct 与 DiT-L MMDiT 动作头，16 层、隐藏维度 1536、32 个注意力头；TTT 每头维度为 48，快速 MLP 隐藏宽度为 128。元训练使用 8 张 H800、DeepSpeed ZeRO-2、全局 batch 128，共 100K 步。内层更新次数为 1，元训练学习率 0.1、测试时为 0.01，记忆损失权重 $$\lambda=0.04$$。外层 AdamW 学习率分别为 DiT $$10^{-4}$$、VLM $$10^{-5}$$。（Table B.1）

## 4. 实验与证据
{: #evidence }

### 实验设置与指标

九项任务覆盖传瓶、清桌、递饮料、物体换位、倒水、盖章、翻牛排、杯子堆叠和多步牛排操作。Orig. 在标准操作间评估；New 在家庭部署条件下同时改变光照、桌高和物体。每个任务、每种条件评估 25 次。指标 **progress** 按预定义子目标给予部分得分，完整完成记为 1，再汇总为百分比。例如递饮料按抓取、运输、放置分别计 0.3、0.3、0.4。（§4.1、附录 D）

<p class="paper-sidenote"><a href="https://arxiv.org/pdf/2607.06988v2#page=6">查看原图</a> · <strong>原文 Fig. 3 · 三种机器人身体与人类数据接口。</strong> 双指夹爪、三指手和灵巧手共同验证视觉记忆对不同动作空间的作用。来源：WAM-TTT，arXiv v2，PDF 第 6 页。</p>

基线包括 LDA、配对数据联合训练 WAM-COTRAIN、直接接收人类视频上下文的 WAM-ICL，以及 π₀.₅ 和作者复现的 EgoScale。前面三项帮助比较同一 WAM 基础上的不同视频使用方式。（§4.2）

### 消融与分析

主消融在 New 条件下对清桌、换位各评估 10 次。完整模型 progress 为 100% / 88.9%；WAM-LoRA 为 30% / 0%；省去元训练为 9% / 0%；省去键值重建为 66.7% / 72%；省去测试适配为 40% / 74.1%。元训练和记忆重建共同建立了人类信息服务机器人控制的接口。（Table 2）

数据比例实验在三个任务上比较机器人与人类示范数：每任务 100 条机器人加 100 条人类示范得到 74.1%，200 条机器人示范为 73.7%，100 条机器人示范为 59.5%。VLM 结构实验中，完整模型清桌 progress 为 100%，纯 DiT 为 72%，随机初始化 VLM 为 80%，冻结 VLM 的元训练方案为 54%。（Table E.1–E.2）

动作伪标签实验为人类视频增加 MANO 重定向和 forward-dynamics 目标，四任务平均 progress 为 28.9%；采用视频预测的人类监督配置为 72.3%。递饮料的光照与空间变化评估中，WAM-TTT 为 66% / 56%，LDA 为 54% / 28%。（Table E.3、Table 3）

## 5. 相关工作
{: #related-work }

**世界—动作联合建模。** LDA-1B [23] 提供视频与动作联合建模基础；Unified World Models [22]、DreamZero [29] 等工作也通过视觉预测连接动作学习。WAM-TTT 将这类联合表征用于部署时行为引导，视频分支成为适配信息进入控制的通道。（§2）

**快速权重记忆。** TTT [50]、Titans [51] 和 Spatial-TTT [52] 将序列信息储存在可更新参数中。WAM-TTT 采用视频侧残差记忆，并用配对的人类—机器人外层目标训练查询与写入的联系。（§2、附录 A）

**人类视频驱动机器人。** EgoMimic [7]、EgoScale [10] 使用人类第一视角数据；MimicDroid [18] 研究人类视频上下文。本文把部署视频转成快速权重，并在同一 WAM 上比较直接上下文条件化与记忆适配。（§2、§4.2）

## 6. Insights · 思考与启示
{: #takeaways }

### 批判性阅读：视频自监督更新，究竟写入动作意图还是场景外观？

内层视频目标同时涉及操作动作、背景与相机运动。外层配对训练让更新服务于机器人控制，但测试时新的背景变化仍可能主导自监督误差，挤占任务相关的记忆更新。

**区分实验。** 保持操作步骤相同而改变背景和相机运动，再固定背景而改变步骤，比较适配前后的动作选择与任务成功率。结合仅视频损失、仅记忆重建和联合目标，可检查哪些更新真正改变了任务意图读取。

### 进一步的阅读联系

**论文结果：自监督适配的有效性来自事先学好的跨模态接口。** 人类视频的预测损失提供部署时可用的学习信号，配对机器人外层目标决定这次更新应该怎样影响动作。元训练消融把这两个环节的联系具体呈现出来：模型要提前学习“怎样利用这种新信息改变控制”。

**阅读联想：context 可以存成输入序列，也可以存成适配后的参数。** 这篇论文的 context 粒度是整段人类操作视频，使用方式是先写入、后执行。对于力反馈问题，可以进一步思考局部动作—力响应片段如何形成记忆，以及接触事件和任务阶段分别对应怎样的写入时机。

**阅读联想：force-conditioned policy 的下一步可以围绕适配信号展开。** 已有策略掌握力输入接口后，研究重点可落在“根据此前动作和力响应，哪些可预测量能够驱动记忆更新，以及这种更新如何改善后续动作”。WAM-TTT 提供了内层可观测信号、外层控制目标相互连接的参照；力响应预测与接触条件推断属于由此延伸出的研究问题。
